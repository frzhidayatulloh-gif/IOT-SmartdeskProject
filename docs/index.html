Catatan sensor browser

Browser tidak selalu memberi akses ke sensor cahaya fisik. Jika Ambient Light Sensor tidak didukung, halaman akan menawarkan kamera sebagai perkiraan kecerahan gambar; nilainya bukan Lux. Akses sensor dan kamera umumnya memerlukan HTTPS (atau localhost) dan izin pengguna. Sensor gerak menggunakan DeviceMotionEvent.
